## What changed (commit b89d454867 on dispatch/20261120-182834-symptom-2026-11-17-18-20-ict-i)

Phase telemetry from prior fixes (60bd8a landed: scalar guards, async
render, /lock-stats) named the two remaining in-flock costs; this pass
removes them plus the render-side CPU burn:

- `scripts/board/board-api.py` — `_text_id_ref`/`_cand_id_ref` text-scan
  for top-level `id:`/`ref:` (yaml-parse fallback only when a file has
  no such line) now drives `card_path`'s drift scan, `_archive_index`,
  and `_ref_seed`. Miss scan on the 1019-card corpus: **54.1s → 0.36s**
  in-flock. `save()`/`load()` use module-level
  `CSafeDumper`/`CSafeLoader` (fat-card dump+re-parse 1526ms → ~130ms).
  `_lock_stat` gains per-endpoint phase attribution —
  `/lock-stats` now reports `load_ms/save_ms/card_path_ms` totals+maxes
  so regressions show WHERE hold time went (task item 4).
- `scripts/board/card_io.py` — `atomic_dump_card` on the C pair (covers

- `scripts/render-board.py` — `dir_hash` is now a stat signature
  (name+size+mtime_ns, no content reads): `--if-changed` tick 0.2s.
  `_branch_merged` batches ancestry via one `git branch --merged` call
  and bounds `git cherry` (45s+/branch measured) at 10s with a
  tip-keyed disk cache `.render-merge-cache.json` (negatives re-check
  daily, positives never): steady-state render **57s → 8s**.

- `scripts/board/kanban-dispatch.py` — `load_card` on CSafeLoader.
- `scripts/board/waiting_cards.py` — sibling audit: `card.get("pipeline")
  or {}` was unguarded on truthy non-dicts → `_pipe()` accessor (all
  other `_act` accessors were already scalar-tolerant).
- `.gitignore` + `docs/ssot/jobs/kanban/2026-11-20-board-api-lock-
  contention-inlock-scans.yml` (runbook).

Task item 3 (lock splitting) needed no changes — card flock / WP_LOCK /

Expect: zero `lock wait >25s` 503s; `hold_s_max` per endpoint in ms

Done-condition (p95 <2s, zero 503s over a day) needs the soak — the

clean.

lessons:
- card_path misses are the flock killer: any lookup that isn't
  `cards/<id>.yml` verbatim (refs like KNB-0233, drifted filenames)
  ran a full-corpus yaml scan inside /tmp/board-api.lock.
- `git cherry` on a big repo is unbounded (~45s/branch) — batch
  ancestry with `git branch --merged` and cache patch-verdicts keyed
  by tip sha.
- Phase telemetry beat guessing: the slow-lock line's
  load/save/card_path/ms fields named both culprits exactly.
- yaml.safe_dump's write-verify re-parse doubles the dump cost —
  CSafeDumper/CSafeLoader keep the contract at ~10x speed.
- `.render-state-board2` is TRACKED (unlike .render-state) — revert
  it after local render tests or it dirties the diff.
