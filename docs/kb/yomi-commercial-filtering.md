# Yomi Commercial Message Filtering

## What it is

Pattern-based filtering system for Yomi daily summarization that reduces processing of low-value promotional content from commercial entities like 7-Eleven and CP ALL.

## Context/Background

Implemented on 2026-08-05 to address issue where daily summarization was processing large volumes of promotional messages from commercial sources, reducing the signal-to-noise ratio and wasting processing resources on low-value content.
