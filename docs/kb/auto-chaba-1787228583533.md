# MCP Debug report UX and data-visualization improvements

## What it is

Refactored the `chaba-h3` MCP Debug savings report from a single long page into a tabbed, impact-aware dashboard.

## Context/Background

The report was becoming hard to scan as the number of monitored hosts and commands grew. All sections (summary, audit, top commands, full command tables, raw-allowed prefixes, and presets) were rendered vertically on one page, pushing the most important tables below the fold.

## Key Details

### New tab structure

- **Overview** — summary cards, status breakdown, "what changed" diff, and top-10 commands.
- **Commands** — full per-host command table with search and a sort dropdown.
- **Prefixes** — raw-allowed command prefix pills grouped by category.
- **Presets** — registered MCP Debug preset score bars.
- **Audit** — failed and negative-savings commands that need attention.
- **Raw JSON** — full `mcp-savings.json` payload for debugging.

### New sort options

The Commands tab can now be sorted by:

- `savings_pct_chars` (efficiency, default)
- `saved_chars` (absolute impact)
- `raw_chars` (raw output size)
- `command` (alphabetical)

### Help and mobile

- The "How to read" panel is hidden by default and toggled via a **Show help** button.
- Tabs are plain HTML/CSS/JS, zero-dependency, with a stacked layout on narrow screens.
