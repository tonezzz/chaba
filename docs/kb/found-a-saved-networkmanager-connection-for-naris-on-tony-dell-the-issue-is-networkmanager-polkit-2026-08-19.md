## Key Details

### Technical Details
Found a saved NetworkManager connection for 'Naris' on tony-dell. The issue is NetworkManager polkit: tony is not authorized to activate the connection. The Wi-Fi interface is healthy, the profile is saved, and only a sudo nmcli connection up Naris is needed. To keep it as a backup, set ipv4.route-metric to a value higher than Ethernet (e.g., 600) or ipv4.never-default yes.
