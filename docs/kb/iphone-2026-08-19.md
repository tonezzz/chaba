## Key Details

### Technical Details
iPhone 2.4GHz Personal Hotspot still not visible after enabling Maximize Compatibility. tony-dell MT7601U adapter is healthy (firmware mt7601u.bin.zst present, iw dev info shows managed mode, rfkill not blocked, txpower 20 dBm). The blocker is Wi-Fi scan permissions: nmcli device wifi rescan returns not authorized by polkit, and iw dev scan requires root. Need user to run sudo nmcli device wifi list --rescan yes to verify the phone is actually broadcasting 2.4 GHz, then fix polkit or use sudo to scan/connect.
