## Why MDDB?

MDDB provides enhanced capabilities over the old file-based system:
- **Semantic Search**: AI-powered search with Ollama embeddings
- **Web Interface**: Modern web UI for browsing and management
- **MCP Integration**: Direct access for AI agents and automation
- **Multi-user Support**: Better collaboration features
- **Automated Backups**: Native backup and restore functionality
- **API Access**: REST API for automation and integration
