# chaba documentation

This directory holds runbooks, investigation journals, and architecture notes for the chaba stack.

## Layout

- `services.md` — live service catalog (ports, compose paths, status)
- `runbooks/` — step-by-step operational procedures
- `investigations/` — one file per issue/bug/investigation
- `adrs/` — architecture decision records
- `kb/` — existing knowledge base (`kb-h3-pages.md`, `plan-brief.md`, `mcp-plan.md`)

## Quick links

- `../Makefile` — one-liner stack commands
- `../stacks/nvr/generate_config.py` — camera registry generator
