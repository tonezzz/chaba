Vector-Search Trend Detection Ideas

Five research directions for extending the THB→XAU signal with vector search, nearest-neighbor pattern matching, and latent-space methods. Charts are illustrative; implementations are tracked in the SSOT job below.

SSOT: docs/ssot/jobs/experiments/2026-08-26-gold-thb-usd-vector-search.yml

1. k-NN pattern matcher on return windows

For each day, build a vector of recent THB, XAU, and USD/EUR log returns. Find the k most similar historical windows. If those neighbors were usually followed by a gold drop, short XAU; if by a gold rally, go long.

2. Regime-embedding with PCA

Compress each multi-day window into its first two principal components. Neighbors in the projected space should belong to the same market regime. Use the XAU outcome of those regime neighbors as the forecast.

3. Similarity-weighted forecast

Instead of a majority vote, weight each neighbor's future XAU return by its inverse distance. The net forecast is a soft score; trade in its direction when the score is large enough.

4. Anomaly / change-point filter

Measure how far the current window is from its k-th nearest historical neighbor. If the distance spikes, the current regime is unfamiliar and the safest action is to go flat until a normal pattern reappears.

5. SSOT / documentation vector search

Use the repo's MDDB vector search to find related causality, time-series, and backtesting notes. This keeps research linked to existing knowledge and avoids duplicating work, but it is not a trading signal.

6. Live out-of-sample equity curves

Cumulative equity (log scale) for the best versions of the implemented vector-search ideas versus buy-and-hold gold. Data is generated by the walk-forward backtests and updated as the experiments progress.
