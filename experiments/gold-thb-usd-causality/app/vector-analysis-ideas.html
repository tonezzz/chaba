Advanced Vector-Analysis Ideas

Six alternative ways to apply vector analysis to the THB→XAU signal. Each card explains the concept; the companion Python scripts will be added one by one. Research only, not a trading system.

SSOT: docs/ssot/jobs/experiments/2026-08-26-gold-thb-usd-vector-analysis.yml

1. Dynamic Time Warping (DTW) similarity

Align two return windows elastically before measuring their distance. This is useful when the THB lead onto XAU can shift by a day or two within the window. A small DTW distance means the current THB path resembles a historical one.

2. Delay-embedding k-NN (Takens-style)

Build a vector from delayed copies of USD/THB returns: [thb_t, thb_{t-1}, thb_{t-2}, ...]. This reconstructs the unobserved phase space of the THB process. k-NN in that space forecasts the next XAU move.

3. Singular Spectrum Analysis (SSA)

Decompose a return series into trend, oscillatory, and noise components by diagonalizing a trajectory matrix. The filtered signal can then feed the existing threshold or k-NN rules.

4. Time-varying / Markov-switching VAR

The static VAR showed a THB shock lowers XAU. A Markov-switching VAR lets that impulse response depend on the current regime (e.g., USD-strength vs USD-weakness), so the forecast adapts to market conditions.

5. Graph / network view

Treat XAU, USD/THB, and USD/EUR as nodes. Build a rolling directed graph from Granger-causality p-values or transfer entropy. Regime shifts appear as clusters or changes in the dominant edge.

6. Wavelet coherence

Run a continuous wavelet transform on THB and XAU. Look for time-frequency bands where the two series are coherent and have a non-zero phase, revealing lead-lag behavior at different horizons.
