  snapshots there when the named file is absent.

  emit_audit_card and shows the CURRENT delta set — always diff it
  against the card's original `spec:` before assuming scope.
- nest-mgr rollout (install.sh fleet + ops-macbook-nestmgr-install)
  landed without ssot.audit.hosts.yml declarations — fleet service
  rollouts need an audit-SSOT declaration step in the same change.

  oneshot service expected-active risks missing-delta flap while asleep.
