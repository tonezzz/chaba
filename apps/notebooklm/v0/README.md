# NotebookLM v0

A static landing page and quick reference for the central NotebookLM deployment.

## Files

- `index.html` — quick reference for `nlm`, `nbapi`, and `nlm-add`
- `README.md` — this file

## What it does

- Lists the CLI/REST helpers installed for NotebookLM
- Shows common commands
- Links to the REST API and SSOT docs

## Notes / v0 limitations

- No server required; it is a static HTML page.
- The REST API link requires the `X-API-Key` header, so a future version may add a proxy or key input.
