---
description: Start a local chaba-h3 preview server
---
1. Run `just -f /home/tony/CascadeProjects/chaba-h3/Justfile serve-php` in the background.
2. Wait for the server to listen on `0.0.0.0:8123`.
3. Open `http://192.168.1.48:8123` in the browser preview.
4. Report the server PID and keep it alive until the user says stop.
