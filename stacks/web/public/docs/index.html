camera system

  • single source of truth: stacks/nvr/cameras.json (34 cameras, 4 groups)
  • generator: python3 stacks/nvr/generate_config.py
  • generated files: stacks/nvr/generated/config.yml and stacks/nvr/generated/camera-map.html
  • web map: stacks/web/public/camera-map.html (sync from generated)

workflow:

  1. edit stacks/nvr/cameras.json
  2. run make nvr-regenerate (or python3 stacks/nvr/generate_config.py)
  3. restart frigate: make nvr-restart
  4. sync web map: make sync

architecture decisions

  • caddy over nginx: caddy on port 8080; simpler config, auto-https ready, reverse proxy built-in
  • separate compose files per stack: independent lifecycles for ai, nvr, and web
  • doh direct ips: 180.180.242.207/208 used instead of domains to avoid tls/sni issues
  • vstarcam transcode: h.265 transcoded to h.264 with libx264; audio dropped due to pcm a-law
  • camera data inline: cameras embedded in camera-map.html to avoid cors and external file loading
