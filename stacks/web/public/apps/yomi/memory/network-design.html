🎨 Design Notes

  • Force-directed layout: Conversations positioned based on relationship strength
  • Node size: Based on memory count, message count, or connection count
  • Node color: Based on conversation category (family, work, personal, etc.)
  • Edge thickness: Based on relationship strength (topic overlap, time proximity)
  • Interactive controls: Filter by relationship type, adjust minimum edge weight
  • Multiple layouts: Force, circular, hierarchical for different perspectives
  • Details panel: Shows selected node info, connections, and shared topics

Relationship Calculation Methods

  • Topic Overlap: Jaccard similarity of topic sets between conversations
  • Time Proximity: Temporal distance between recent messages
  • Participant Overlap: Shared participants between conversations
  • Message References: Cross-conversation message references

Implementation Priority

Phase 1: Basic Network View

  • Simple force-directed layout using canvas
  • Basic node rendering with category colors
  • Topic overlap relationship calculation
  • Interactive node selection
  • Details panel with connection info

Phase 2: Enhanced Features

  • Multiple relationship types (time, participants)
  • Advanced layout algorithms (circular, hierarchical)
  • Interactive controls (zoom, pan, filters)
  • Edge thickness based on relationship strength
  • Node size options (memory count, message count)

Phase 3: Advanced Features

  • Real-time network updates
  • Path finding between conversations
  • Community detection algorithms
  • Network statistics and metrics
  • Export network data
