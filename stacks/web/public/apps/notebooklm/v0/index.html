NotebookLM v0

Quick reference for the central NotebookLM deployment on tony-dell.

CLI helpers

  • nlm — wrapper for the notebooklm-mcp container
  • nbapi — REST API helper for /v1/notebooks
  • nlm-add — upload a local file to Drive and add it to a notebook

Common commands

nlm create notebook "My KB"
nlm-add <notebook-id> /path/to/file.md -t "Title"
nlm notebook list
nbapi /v1/notebooks
