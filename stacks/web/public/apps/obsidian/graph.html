● colored sphere = memory doc — color is the bank

bright solid = in MDDB + vault (or MDDB-only) · faded = vault-only, retracted, or superseded
● red = dangling supersedes link (broken provenance)
— thick amber edge = supersedes (old → new)
··· faint edge = semantic similarity (enable in toolbar)
