Memory Graph

How to read this
● colored sphere = memory doc — color is the bank (click a chip below to hide/show a bank)
● grey sphere = hub — a subject: topic or entity: shared by 2+ docs
bigger sphere = more links / more voice recalls
bright = MDDB (+vault) · faded = vault-only, retracted, or superseded
● red = dangling supersedes link (broken provenance)
— amber edge + arrow = supersedes (new → old)
··· faint edge = semantic similarity (enable in toolbar)
oversized subjects split into sub-hubs by month/day
drag to rotate · scroll to zoom · right-drag to pan · hover highlights the neighborhood · click centers the camera + shows details (with local·N set, filters to its neighborhood) · double-click a doc opens the vault, a hub collapses/expands it, a pinned node releases it · drag a node to pin it
keys: / search · f fit · space pause · esc clear
