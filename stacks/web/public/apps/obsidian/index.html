About this app

Review/edit tier for Ada's memory banks. Each left-sidebar folder maps 1:1 to an ada-ha-bank-* collection in MDDB — what Ada recalls by voice.

  1. Select a note → Edit → Save (writes the vault file only)
  2. Push to Ada syncs vault → MDDB so Ada sees it
  3. Sync + queue commit also queues the hourly git commit on tony-omen
  4. Queue lists MDDB-only docs not yet in the vault — export them to review
