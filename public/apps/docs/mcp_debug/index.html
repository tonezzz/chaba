How to read this report

Raw chars — output size if run with mcp_raw (full shell output).
Compact chars — output size after mcp_debug formatting (JSON or tables).
Char % — character savings; green means compact is smaller, red means it grew.
Word % — word/token savings; useful when the output is mostly text.
Tokens saved — approximate LLM tokens (chars / 4) saved per command.
Status — recommended smaller on every host, negative if it grew, failed if it errored.

Live data is fetched directly from the tony-dell Tailscale Funnel endpoint. If tony-dell is unreachable, the page falls back to the cached data/mcp-savings.json snapshot.
