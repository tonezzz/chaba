Race Manager Help

Getting Started

Welcome to Race Manager! This tool helps you create, edit, and simulate race courses for sailing competitions.

  • Use the COURSE tab to view course information and manage markers
  • Use the MAP tab to toggle course elements visibility
  • Use the SECTIONS tab to manage race sections and their properties
  • Use the SIM tab to configure wind and run race simulations
  • Use the YAML tab to edit course configuration directly

Marker Management

Markers define the key points of your race course:

  • Add Marker: Click "+ Add Marker" to create a new marker at map center
  • Select Marker: Click on a marker in the list or on the map to select it
  • Delete Marker: Select a marker and click "Delete Selected" to remove it
  • Move Marker: Drag markers on the map to reposition them

Section Editing

Sections define the race path between markers:

  • Edit Section: Click "Edit" next to a section to modify its properties
  • Width: Adjust the corridor width for the section (1-100m)
  • Color: Choose a color to highlight the section on the map
  • Rounding: Set the rounding direction (starboard/port) for buoy sections

Course Validation

Ensure your course is properly configured:

  • Click "Validate Course" to check for errors and warnings
  • Validation checks marker coordinates, references, and orphaned markers
  • Results are shown in notifications and logged to the console

Undo/Redo

Easily revert changes with undo/redo functionality:

  • Undo: Click "Undo" or press Ctrl+Z
  • Redo: Click "Redo" or press Ctrl+Y
  • Up to 50 states are saved in history

Keyboard Shortcuts

  • Ctrl+Z - Undo last action
  • Ctrl+Y - Redo last action
  • Ctrl+Shift+Z - Redo last action (alternative)
  • Ctrl+S - Save course
  • Ctrl+N - Add new marker
  • Ctrl+D - Duplicate selected marker(s)
  • Ctrl+A - Select all markers
  • Delete - Delete selected marker(s)
  • Escape - Deselect marker(s) / Close dialogs
  • Ctrl+E - Export course
  • Ctrl+I - Import course
  • Ctrl+H / F1 - Open help
  • Ctrl+T - Start guided tour
  • Tab / Shift+Tab - Navigate tabs
  • Ctrl+V - Validate course
  • L - Toggle leader focus in simulation

Simulation

Run realistic race simulations:

  • Configure wind direction, speed, and gust factor
  • Set number of racers and simulation speed
  • Click "Start" to begin the simulation
  • Use "Focus Leader" to track the leading boat
